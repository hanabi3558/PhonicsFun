<h1>PhonicsFun!</h1>

**Learn sounds, words & blending**

An interactive phonics learning app for kids, covering Phase 1–6 of the UK phonics curriculum.

[**Try it live**](https://hanabi3558.github.io/PhonicsFun/)

</div>

---

## Features

**4 Learning Modes**

- **Flashcards** — Learn each phoneme with sound, word and emoji. Tap to flip, swipe to navigate.
- **Quiz** — Multiple-choice questions to test sound-to-word and word-to-sound recognition.
- **Match** — Memory card game to pair phonemes with their words. 3 difficulty levels.
- **Blending** — Sound out words phoneme by phoneme, with adjustable speed.

**6 Phases**

| Phase | Focus | Examples |
|-------|-------|---------|
| 1 | Alphabet Sounds | a-z |
| 2 | Phonics Sounds | s, a, t, p, ck, ff, ll, ss |
| 3 | Digraphs & Vowels | ch, sh, th, ai, ee, igh, oa |
| 4 | Consonant Clusters | st, nd, tr, bl, scr, str |
| 5 | Advanced Vowels | ay, ou, ie, a_e, i_e, o_e |
| 6 | Tricky Patterns | dge, kn, wr, tion, ture |

**Other Highlights**

- Real MP3 phoneme sounds for accurate pronunciation
- Text-to-speech fallback via Web Speech API
- Progress tracking with stars and per-phase learned counts
- Saved locally in browser (localStorage)
- Mobile-friendly, works offline
- No install needed — pure HTML/CSS/JS

## Getting Started

Just open `index.html` in a browser. No build step, no dependencies.

Or visit the live version: https://hanabi3558.github.io/PhonicsFun/
